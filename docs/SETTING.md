# Setting: the Érinska Narodna Poblacht

This sheet keeps names, signage and in-game text consistent. The tone is a quiet,
grey, *lite* dystopia. Life is regulated, rationed and slow, but in this slice
nobody is spying on you. The player is an ordinary citizen getting through the day.

## The state

| | |
| --- | --- |
| **Name** | Érinska Narodna Poblacht (ÉNP), the Érin People's Republic. Signs: ЕРИНСКА НАРОДНА ПОБЛАХТ |
| **Capital** | **Dubrava** (Дубрава). Irish *Duibhlinn* crossed with Slavic *dubrava*, "oak grove" |
| **Currency** | **púnt** (пунт) = 100 **pingin** (пингин). Written `3.80 p.` |
| **Rationing** | Monthly coupon books (*talóny*) for sugar, butter and meat. Coupons are needed *and* you still pay |
| **Ministries** | *Aireacht* ("ministry"): Aireacht Soláthair (Provision), Aireacht Tithíochta (Housing), Aireacht Saothair (Labour) |
| **Newspaper** | *Fírinne* ("Truth") |
| **Radio** | Raidió Náisiúnta, Dubrava Programme One, on the wired kitchen *radiopunkt* |
| **Weather** | Damp. Drizzle is the default state of the sky. |

## The language: Érinski

Irish vocabulary with Slavic endings and grammar. Official signs are in **Cyrillic**;
everyday writing (and the game UI) uses a **Latin** transliteration with Irish fadas
and Slavic háčeks.

Rules of thumb for coining words:
- Take the Irish word and simplify its spelling to how it sounds: *arán* → АРАН, *siopa* → СИОПА.
- Plurals take a Slavic *-i* / *-y*: *bróg* → БРОГИ, *bláth* → БЛАХИ.
- Abstract nouns and institutions take *-ija* / *-ika*: ГРОСЕРИЯ (grocery), ПОТИГЕРИЯ (pharmacy).
- Where Irish and Slavic already agree, keep it: ПОШТА, КВАС.

## Work

The player works at **Dubrava Tractor Works No. 3** (*Monarcha Traktorov Uimh. 3*) as a
lathe operator: 08:00 to 17:00, Luanek to Aoinek, 3.80 p. a shift. Bus 14 runs from
the stop on the district's edge from 06:30. The ride takes 25 minutes.
